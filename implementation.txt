PROJECT OVERVIEW
----------------
A modern, responsive, full-stack developer portfolio web application.
- Frontend : React 18 + Vite + Tailwind CSS + Lucide React icons
- Backend  : FastAPI (Python) REST API
- Theme    : Dark mode, blue/purple/cyan brand palette
- Sections : Navbar, Hero, About, Skills, Projects, Experience, Contact, Footer

================================================================================

-------------------------------

uvicorn[standard]==0.29.0
pydantic[email]==2.6.4

NOTE: pydantic[email] is REQUIRED because schemas.py uses EmailStr.

FILE: backend/main.py
---------------------
- Create FastAPI app with title, description, version
- Add CORSMiddleware (allow all origins for dev; restrict in production)
- Include routers: projects, skills, experience, contact
- GET / → return app status info
- GET /api/health → return {"status": "healthy"}

--------------------------------------------------------------------------------

FILE: backend/models/schemas.py
--------------------------------
Pydantic models:

  Project:
    - id: str
    - title: str
    - description: str
    - category: str  (Full Stack | Frontend | Backend | AI/ML | DevOps)
    - tags: List[str]
    - image: str  (URL)
    - live_url: Optional[str]
    - github_url: Optional[str]
    - featured: bool = False

  SkillDetail:
    - name: str
    - level: int  (1-100)
    - category: str
    - icon: Optional[str]

  Experience:
    - id: str
    - role: str
    - company: str
    - location: str
    - period: str
    - description: str
    - achievements: List[str]
    - technologies: List[str]

  ContactRequest:
    - name: str  (min 2, max 100)
    - email: EmailStr
    - subject: str  (min 2, max 150)
    - message: str  (min 10, max 2000)

  ContactResponse:
    - success: bool
    - message: str
    - timestamp: str

FILE: frontend/src/services/api.js
------------------------------------
Base URL: /api  (proxied via Vite to http://127.0.0.1:8000)

Functions:
  fetchProjects(category)  → GET /api/projects or /api/projects?category=X
                             fallback: return 3 static projects on error
  fetchSkills()            → GET /api/skills/categorized
                             fallback: return static categorized skills object
  fetchExperience()        → GET /api/experience
                             fallback: return 2 static experience objects
  sendContactMessage(data) → POST /api/contact with JSON body
                             throws Error on non-ok response
